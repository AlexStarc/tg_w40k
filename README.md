# tg_w40k

A Telegram bot that collects messages from a group chat and generates daily "chronicles" — narrative summaries written in the style of Warhammer 40K lore, using an LLM.

## Features

- Collects messages from a monitored Telegram group chat
- Filters out spam and low-effort single-message users
- Generates daily narrative summaries via GLM API in WH40K style
- Admin commands to review and publish summaries
- SQLite storage for messages and summaries

## Setup

1. Create a bot via [@BotFather](https://t.me/BotFather) and get the token
2. Add the bot to your target group chat
3. Copy `.env.example` to `.env` and fill in the variables:

```
BOT_TOKEN=<your-bot-token>
ADMIN_ID=<your-telegram-user-id>
CHAT_ID=<target-group-chat-id>
GLM_API_KEY=<your-glm-api-key>
MEME_CHANNEL_ID=<@crisiswoman-channel-or-id>      # optional, enables meme publishing
PEXELS_API_KEY=<your-pexels-api-key>              # optional, image sources —
UNSPLASH_API_KEY=<your-unsplash-api-key>          #   any subset works; the
PIXABAY_API_KEY=<your-pixabay-api-key>            #   fallback chain covers the rest
TG_API_ID=<your-telegram-api-id>                  # optional, learn from channels —
TG_API_HASH=<your-telegram-api-hash>              #   get at my.telegram.org
TG_SESSION=tg_w40k_user                           #   session name (created via auth_telethon.py)
MEME_SOURCE_CHANNELS=@kateeeeg,@danya_vologda     #   channels to harvest captions/style from
MEME_HARVEST_PER_CHANNEL=3                        #   pairs to extract per channel per run
```

> `MEME_CHANNEL_ID` may be a numeric channel id or `@username`. The bot must be an admin
> of that channel. Omit it to keep the meme generator in preview-only mode.
> Image sources are a fallback chain: configured keyed services + Openverse (no key) →
> Lorem Picsum (guaranteed). Meme generation works with **zero** image API keys.
> `MEME_SOURCE_CHANNELS` is optional. If set, run `python auth_telethon.py` once (after
> filling `TG_API_ID`/`TG_API_HASH`) to authorize a user-mode Telegram session; the bot
> then harvests captions from those channels for both punchline extraction and style
> orientation (see below).

4. Install dependencies and run:

```bash
pip install -r requirements.txt
python main.py
```

## Commands

### Chronicles

| Command | Description |
|---|---|
| `/summary` | View the latest daily chronicle (admin only) |
| `/send_to_chat` | Publish the latest chronicle to the group (admin only) |

### Memes (Crisiswoman)

| Command | Description |
|---|---|
| `/meme` | Generate a meme, send it to the admin for review (admin only) |
| `/meme_add quote :: punchline :: dark` | Append a quote+punchline pair to `bank.json` (`:: tone` optional, default `light`) |
| `/meme_seed [N]` | Generate N (default 8) new quote pairs via GLM and append to the bank (admin only) |
| `/meme_harvest` | Pull fresh captions from `MEME_SOURCE_CHANNELS` and extract new pairs via GLM (admin only; needs Telethon) |
| `/meme_channels` | Show source-channel status: cached posts count, last fetch time, Telethon auth state (admin only) |

## How It Works

### Chronicles

1. The bot listens for messages in the configured group chat
2. Messages are stored in a local SQLite database
3. Every day at 00:05 (Moscow time), the bot summarizes the previous day's messages
4. Only messages from users with multiple distinct messages are included (spam is filtered out)
5. The summary is generated by an LLM (GLM-5-Turbo) using a WH40K-themed system prompt
6. The admin receives a notification and can review/publish the chronicle

### Meme generator (Crisiswoman)

A literary-meme pipeline that runs in parallel with the chronicles. It composes a
literary/feminist quote with a mundane punchline over a real stock photo and sends
the result to the admin for review before publishing to the configured channel.

1. `/meme` picks a quote from `bank.json`, a random visual **style** (one of
   `bottom / bars / poster / split / minimal / hand`), and fetches a **real**
   background photo — Pexels API (tag-based) by default, falling back to
   Lorem Picsum (occasionally grungy/ugly, never AI-generated)
2. The rendered image is sent to the admin with inline buttons:
   **📤 Publish · 🎨 New style · 🔄 New quote · ⭐1–5 rating · ❌**
3. Ratings are stored in `meme_ratings` and feed back into generation: poorly-rated
   quotes are dropped, well-rated quotes and styles are picked more often, while a
   20% exploration rate keeps the pool from collapsing
4. New material enters `bank.json` via `/meme_add` (or by hand); the file is plain
   JSON, so it can be edited or re-seeded freely. `bank.json` is gitignored (it
   mutates at runtime like `bot.db`); the curated baseline lives in the tracked
   `bank.seed.json`, and the bot auto-seeds `bank.json` from it on first run.
5. The bank also **auto-refreshes**: a scheduled GLM job (04:00 MSK, alongside the
   daily chronicle cycle) generates ~8 new pairs and appends them (deduped). Growth
   is capped (oldest auto-pairs pruned beyond 120). Since freshly-added pairs start
   unrated, weak ones sink out of rotation once rated low — the feedback loop keeps
   the bank clean. `/meme_seed N` triggers a manual refresh
6. **Channel learning** (optional, requires a Telethon user-session): set
   `MEME_SOURCE_CHANNELS=@chan1,@chan2,…` and `TG_API_ID`/`TG_API_HASH` in `.env`,
   then run `python auth_telethon.py` once to log in (phone + code + optional 2FA).
   The bot reads captions from those channels in two ways:
   - **Harvest**: each daily refresh (and on-demand via `/meme_harvest`) pulls new
     captions via Telethon, caches them in the `channel_posts` table, and asks GLM
     to extract up to `MEME_HARVEST_PER_CHANNEL` new quote pairs per channel in the
     Crisiswoman format. Pairs land in `bank.json` with `source = @channel` so they
     are traceable.
   - **Style orientation (few-shot)**: every `/meme_seed` run prepends a small
     random sample of cached captions to the GLM prompt as a style reference, so
     freshly generated pairs drift toward the tone/rhythm of the channels you like.
   `/meme_channels` shows per-channel cache size, last fetch time, and Telethon auth
   state. Disable any time by clearing `MEME_SOURCE_CHANNELS` — the bot falls back
   to the GLM-only seed flow.

## Deployment

Run as a systemd service. Fonts are bundled in `fonts/` (OFL-licensed, Cyrillic),
so the renderer is self-contained and works on any Linux host.

First-time setup:

```bash
sudo useradd -m tgw40k
git clone <repo> /opt/tg_w40k && chown -R tgw40k:tgw40k /opt/tg_w40k
sudo -u tgw40k bash -c 'cd /opt/tg_w40k && python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt'
cp .env.example /opt/tg_w40k/.env   # then edit in BOT_TOKEN, ADMIN_ID, CHAT_ID, GLM_API_KEY, MEME_CHANNEL_ID, ...
```

`/etc/systemd/system/tg_w40k.service`:

```ini
[Unit]
Description=tg_w40k bot
After=network.target

[Service]
Type=simple
User=tgw40k
WorkingDirectory=/opt/tg_w40k
EnvironmentFile=/opt/tg_w40k/.env
ExecStart=/opt/tg_w40k/.venv/bin/python main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now tg_w40k
journalctl -u tg_w40k -f
```

Updating an existing install:

```bash
cd /opt/tg_w40k
sudo -u tgw40k git pull
sudo -u tgw40k .venv/bin/pip install -r requirements.txt   # picks up new deps (e.g. pillow)
sudo systemctl restart tg_w40k
```
